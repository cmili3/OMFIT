# OMFIT – Landing page

Sitio estático (HTML + CSS + JS), sin dependencias. Listo para GitHub Pages.

## Archivos a agregar en `assets/`
- `logo.png`   → logo (favicon y póster del video)
- `hero.mp4`   → video de inicio con el logo
- `omar.jpg`   → foto de Omar (vertical, proporción 4:5)
- `banner.jpg` → fondo del banner motivacional

## Cambiar antes de publicar
- WhatsApp: reemplazá `5492610000000` en `index.html` (formato internacional, sin +).
- Instagram: reemplazá `instagram.com/omfit` por tu usuario.

## Publicar
Subí todo al repo → Settings → Pages → Branch `main` / carpeta raíz.
